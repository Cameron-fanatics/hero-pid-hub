Data Clean-up
Corrupted Player Names
Export players with encoding issues in their name or shirt name. Correct the Name and Shirt Name columns, then re-upload.
Clubs — Incomplete Data
Flags clubs missing Sport, League, or Country. CSV columns: ClubID, Name, Sport, League, Country
Seasons — Incomplete Data
Flags seasons missing a Label. CSV columns: SeasonID, Label
Players — Incomplete Data
Flags players missing Squad Number or Shirt Name. CSV columns: PlayerID, Name, ShirtName, SquadNumber, Club, Season
Parent PIDs — Incomplete Data
Flags parent PIDs missing a PID value, or missing CustomSKU for US sport clubs. CSV columns: ParentID, PID, GarmentType, CustomSKU, Club, Season
Hero PIDs — Incomplete Data
Flags hero PIDs missing ParentPID, KitType, or GarmentType. For US sport clubs also flags missing ProductTitle, Gender, or JerseyColour. CSV columns: HeroID, PID, GarmentType, KitType, ParentPID, ProductTitle, Gender, JerseyColour, Player, Club, Season
MDM Roster Members — Incomplete Data
Flags roster members where the Roster Member ID is 0 (MDM hasn't assigned an ID yet) or Roster ID is missing. CSV columns: RosterMemberID, RosterID, JerseyName, PlayerName, JerseyNumber, ActorID, Club
