Homeplate Parents: garment from the product name

1) Export the parent PIDs and put them into Homeplate. 2) Drop Homeplate's product export (columns Product ID and Name) below. The garment is read from the product name (Home/Away/Third/Goalkeeper Shirt, "- Long Sleeve", "- Womens", "- Kids", "Infant/BabyKit"). Names that do not fit that pattern, or whose kit or season disagrees with the parent, are listed for review and never used. Parent garments change first; hero PIDs on those parents are then re-derived to match.

Player ActorID Sync
Populates MDMActorID on Player records by matching against MDM Roster Members. Uses tiered matching: Jersey Name first, Full Name fallback. Conflicts are skipped.
Data Integrity Check
Checks that players, hero PIDs and MDM agree on who each ActorID belongs to. The check changes nothing. Only the repairable group can be fixed here: a PID whose ActorID differs from its player, where MDM positively confirms that player's ActorID. Anything MDM can't confirm is listed for you to review. Run this before the player deduplication.
Parent Link Check
Checks that each hero PID hangs off the right parent: goalkeepers on goalkeeper parents, outfield players on outfield parents, garments that agree with the parent, and no "other" garments. Parents have no goalkeeper flag, so a likely goalkeeper parent is inferred from the PIDs currently on it (at least 3 PIDs, 60% or more belonging to goalkeepers); a likely outfield parent has at least 8 PIDs and at most 10% goalkeepers. If those PIDs are themselves mis-linked the inference can be wrong, and a clean result does not prove the links are right. The check changes nothing; to fix links, use Re-link in the Import preview with the club's sheet.
Player Deduplication Preview
Shows player records that share the same ActorID + ClubID and would be merged in Step 9. Uses canonical scoring to identify which record would be kept.
⚠ Preview only. No Airtable records will be changed. Use the Merge Duplicate Players card below to act on it.
Merge Duplicate Players
Merges each duplicate pair into the kept player: the spare's PIDs are moved across, read back to confirm, and only then is the spare record deleted. Every pair is re-checked against live Airtable data first. The run stops at the first error.
⚠ This DELETES player records. Refresh the tool first, and pause imports and other edits to Players and Hero PIDs while a run is in progress. Start with a small pilot (about 5 pairs at one club), check the result, then continue.
